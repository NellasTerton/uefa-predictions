# ⚽ UEFA Predict 26/27

Мобильное PWA для футбольных прогнозов среди друзей: Лига чемпионов, Лига Европы и Лига конференций сезона 2026/27 в одном приложении, с общим рейтингом и разбивкой очков по турнирам.

A mobile-first PWA for friendly football forecasting: the Champions League, Europa League and Conference League of season 2026/27 in one app, with a shared leaderboard and a per-tournament breakdown of points.

## 💡 Идея

Азарт и споры вокруг футбольных прогнозов — без единой копейки на кону. Своего рода «экологичная лудомания»: играешь не против букмекера, а против друзей, и единственная ставка — твоя репутация знатока.

---

## 🌟 Что умеет

**Три турнира в одном приложении.** Переключатель в шапке: ЛЧ, ЛЕ, ЛК. У каждого своя таблица общего этапа, свои туры (8, 8 и 6 соответственно) и свой цвет.

**Общий рейтинг с разбивкой.** Очки суммируются в одну таблицу лидеров, но каждый игрок видит, где именно он их набрал: сколько в Лиге чемпионов, сколько в Лиге Европы, сколько в Лиге конференций — и у себя, и у соперников. Плюс бейдж «лучший турнир».

**Начисление очков.** 5 за точный счёт, 2 за угаданный исход, 0 мимо.

**Защита от поздних ставок.** Прогноз блокируется по времени стартового свистка — и на клиенте, и на сервере, независимо от того, с какой задержкой приезжает статус матча.

**Мгновенный отклик.** Прогноз появляется на карточке сразу, не дожидаясь ответа базы, и подтверждается короткой анимацией. Если запись сорвалась — карточка откатывается назад.

**Два языка.** Полная локализация RU / EN, переключение на лету.

**Установка на телефон.** Веб-манифест и iOS-теги: приложение ставится на домашний экран и открывается без браузерных панелей.

**Удаление аккаунта.** Профиль, прогнозы и сам вход удаляются безвозвратно, с подтверждением вводом никнейма.

## 🛠 Как это устроено

**Фронтенд.** React + Vite + Tailwind CSS. Тёмная неоновая тема, вёрстка под телефон. Полностью статическая сборка — серверного рендеринга нет.

**Бэкенд.** Supabase: авторизация, PostgreSQL, Row Level Security и Edge Functions на Deno.

**Откуда берутся матчи.** Расписание, составы и эмблемы генерируются из публичного API ESPN скриптом `generate_competitions.js` в файл `src/data.ts`. Это снимок сезона: за сезон он не меняется, поэтому лежит в сборке, а не запрашивается на лету.

```bash
node generate_competitions.js
```

**Откуда берутся результаты.** Edge Function `uefa-sync` раз в 10 минут (по расписанию `pg_cron`) опрашивает те же три турнира у ESPN, обновляет счёт и статус в таблице `matches`, пересчитывает очки за прогнозы и пересобирает таблицу лидеров. Матчи сопоставляются по идентификатору ESPN — тому же, что в снимке, — поэтому сверка точная, без сопоставления по названиям команд.

Приложение берёт из базы только то, что меняется: счёт и статус. Всё остальное — из снимка.

**Стадии турнира.** Общий этап размечается по турам, плей-офф — по стадиям (1/16, 1/8, 1/4, 1/2, финал), которые отдаёт ESPN. Матчи навылет не участвуют в нумерации туров и не попадают в таблицу общего этапа.

## 📱 Установка на телефон

**iPhone (Safari).** Открыть ссылку → кнопка «Поделиться» → «На экран „Домой“».

**Android (Chrome).** Открыть ссылку → меню из трёх точек → «Установить приложение».

---

## 🚀 Локальный запуск

```bash
npm install
```

Создать `.env.local` рядом с `package.json`:

```
VITE_SUPABASE_URL="https://<ваш-проект>.supabase.co"
VITE_SUPABASE_ANON_KEY="<публичный ключ>"
```

```bash
npm run dev
```

Без ключа приложение запустится, но покажет предупреждение: вход, прогнозы и рейтинг работают только с базой.
